# CLD Optimization Experiments

Code for the numerical experiments accompanying the associated research paper.
The paper describes the mathematical setup, algorithm, and interpretation of
the results. This repository contains the implementation and the exact
configuration files used for the final five-seed run.

## Requirements

The final configurations require Linux with a CUDA-capable GPU. They were run
with Python 3.11, PyTorch 2.4.1, and CUDA 12.1. Create the Conda environment
from the repository root:

```bash
conda env create -f environment.yml
conda activate cld-opt
```

Run all commands below from the repository root. The scripts intentionally
reject other working directories so that relative configuration and output
paths resolve consistently.

## Run the final experiment

The five canonical configurations differ only in their seed. Run each command
on a CUDA GPU; they may be launched independently when multiple GPUs are
available.

```bash
python scripts/run_exp_from_config.py --config configs/seed0.yaml
python scripts/run_exp_from_config.py --config configs/seed1.yaml
python scripts/run_exp_from_config.py --config configs/seed2.yaml
python scripts/run_exp_from_config.py --config configs/seed3.yaml
python scripts/run_exp_from_config.py --config configs/seed4.yaml
```

The `configs/test_seed*.yaml` files are smaller GPU sanity configurations.
They are not the paper configurations.

## Merge and plot locally generated results

Runs write checkpoints under the configured local checkpoint directory. These
checkpoints, generated plots, and logs are deliberately ignored by Git and are
not distributed with this repository.

After running all five seeds, merge the five checkpoint paths printed by the
run commands (replace the placeholders below with your own paths):

```bash
python scripts/merge_metric_checkpoints.py \
  --out cld_checkpoints/merged_metrics.pt \
  <seed-0-checkpoint> <seed-1-checkpoint> <seed-2-checkpoint> \
  <seed-3-checkpoint> <seed-4-checkpoint>
```

Create the standard metric plots from the merged checkpoint:

```bash
python scripts/plot_checkpoint.py cld_checkpoints/merged_metrics.pt --outdir plots/final
python scripts/plot_metric_per_seed.py cld_checkpoints/merged_metrics.pt \
  --metric feat_gram_lambda_hist --outdir plots/final
```

Use `--help` with any script for its available options. Checkpoints are Python
serialization files; only load files generated by you or obtained from a
trusted source.
